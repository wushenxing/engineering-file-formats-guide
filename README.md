# 工程科研与机器人常见文件后缀详解

面向软件工程、人工智能科研与机器人开发的中文文件格式学习资料，按工作环节解释常见文件的用途、生成工具、读取方式和使用条件。

## 下载学习文档

[下载 Word 文档](docs/工程科研与机器人常见文件后缀详解_小四论文排版版.docx)

进入文件页面后点击下载按钮，或点击 **Code → Download ZIP** 下载完整仓库。Word 文档可继续编辑，GitHub 网页通常不能直接预览其正文。

## 文档内容

- 文件后缀、内部格式与业务语义的区别。
- 软件源码、网页界面、脚本、配置、构建和分发文件。
- 科研文档、文献、表格、数组、数据库、媒体、模型、标注和日志。
- 机器人 CAD、工程图、网格、PCB、固件、仿真、通信与传感器记录。
- 移动机器人项目全流程案例，以及文件选择、交付和复现建议。

全文包含 **150 个文件条目、9 个主章节和 25 条参考文献**。同一后缀在不同领域的含义会分别解释，条目数不表示互不重复的后缀数量。
